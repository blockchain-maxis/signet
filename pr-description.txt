## Problem
Contract pages are not currently included in the sitemap, which prevents them from being discovered by search engines.

## Root cause
The `sitemap.ts` file only generates URLs for static routes and profile handles. It does not query the database for deployed contracts.

## Fix
Added a `listAttributedContracts` query in `apps/web/lib/profile-contracts.ts` that joins `Contract -> Wallet -> Profile` on the configured network. Wired this into `apps/web/app/sitemap.ts` to output `<loc>` tags for each contract page, capped at 45,000 to remain within the 50,000 URL limit.

## Testing
- Modified `apps/web/lib/sitemap.test.ts` to cover `contractRoutes` URL shape and `lastModified`.
- Added an e2e test in `apps/web/e2e/smoke.spec.ts` to ensure `GET /sitemap.xml` on the e2e server (which has no DB) gracefully returns only the static routes.
- Ran all tests successfully.
