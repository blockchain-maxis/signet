# `@signet/fixtures`

Recorded responses from Stellar testnet to support offline unit tests for indexer workers, spec readers, and XDR decoding suites.

## Invariants

- **Real recordings:** Every JSON fixture under `data/` was captured directly from live testnet RPC / Horizon endpoints.
- **Never edit fixtures by hand:** All fixtures are generated by the capture script. Manual edits invalidate the provenance and XDR parsing contracts.
- **Not for production code:** This package is private and development/test-only. Nothing in `@signet/fixtures` may be imported by runtime production applications (`apps/web`, `apps/indexer`, `packages/sdk`, etc.).

## Refreshing Fixtures

To refresh all recordings against testnet:

```bash
pnpm --filter @signet/fixtures run capture
```

Or from the workspace root:

```bash
pnpm --filter @signet/fixtures capture
```

## Available Fixtures

- `registry-instance-entry`: Soroban `getLedgerEntries` response for the Identity Registry's instance key (`LedgerEntryData` / `ContractDataEntry`).
- `sac-instance-entry`: Soroban `getLedgerEntries` response for the native XLM SAC contract instance entry.
- `contract-wasm-entry`: Soroban `getLedgerEntries` response for the Identity Registry's WASM code entry (`ContractCodeEntry`).
- `horizon-contract-deploy-tx`: Horizon `/transactions/{hash}` record for the same deployment as `deploy-get-transaction`, verbatim. Current Horizon does **not** return `result_meta_xdr`; the meta is in the RPC fixture.
- `claim-get-transaction`: Soroban `getTransaction` response for an on-chain Identity Registry `claim` invocation.
- `deploy-get-transaction`: Soroban `getTransaction` response for a real create-contract (`HostFunctionTypeCreateContract`) deployment; `resultMetaXdr` is `TransactionMeta` v4 and returns the new contract address.

- `sac-transfer-call-get-transaction`: Soroban `getTransaction` response for a lending contract's `repay_obligation_liquidity` whose auth tree names a sub-call to a Stellar Asset Contract `transfer` (an `auth-tree` call edge, #516).
- `footprint-only-call-get-transaction`: Soroban `getTransaction` response for the same contract's `borrow_obligation_liquidity`, whose footprint holds a foreign contract instance that neither the auth tree nor any contract event names (a `footprint` call edge, #516).

## Retention

Soroban RPC only serves `getTransaction` for a retention window (about 7 days). `claim-get-transaction`, `deploy-get-transaction` and the two `*-call-get-transaction` fixtures are pinned to transaction hashes in `scripts/capture.ts`; when a hash ages out, pick a newer one of the same kind and update the constant before re-running `capture`. To record only some fixtures, name them: `pnpm --filter @signet/fixtures capture sac-transfer-call-get-transaction`.

## Import guard

`pnpm check:fixtures` (run in CI) fails if production code imports this package.
